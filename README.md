# Rishabh Raj’s portfolio

A one-page Astro site with an introduction, selected work, and contact links.

Install Node.js 24 and pnpm. Run `pnpm install --frozen-lockfile`, then `pnpm dev`. Open the local URL printed by Astro.

Run `pnpm build` to generate the static site in `dist/`. Run `pnpm preview` to serve that build locally.

Edit the copy in `src/pages/index.astro` and the layout in `src/style.css`.
